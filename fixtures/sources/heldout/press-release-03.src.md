The cultural centre [[e:Coral Thread]] announced a repair workshop for [[d:next Friday]]. Each repair demonstration will take [[n:5 to 7 minutes]], according to programme note [[v:FIX-5703]]. The host said [[q:“Bring a broken object that can be carried safely.”]] Visitors must not bring damaged batteries or exposed electrical wiring into the room. Most demonstrations concern hinges, fabric tears and loose handles. The event is a learning session rather than a promise that every object will be repaired. Some objects may need specialist attention, and the host will explain that limitation before any work begins. Visitors should keep the original packaging if it helps show how the object was assembled.
