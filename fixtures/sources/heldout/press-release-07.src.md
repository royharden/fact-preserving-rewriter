The reading collective [[e:Maple Echo]] announced [[n:twelve]] portable book displays on [[d:October 23, 2026]]. Its catalogue note [[v:BOOK-1223]] quotes the organiser: [[q:“A display should invite browsing without blocking the doorway.”]] All borrowing venues must check the exit route before positioning a display. The collective does not require a venue to host an event, and some borrowers plan to use the displays during ordinary opening hours. Most shelves can be rearranged without tools. The catalogue describes how to secure the display on an uneven floor, while the borrowing agreement asks staff to stop using a unit if its stabilising feet cannot be adjusted safely.
