The foundation [[e:Blue Acorn]] committed [[n:half a million dollars]] on [[d:October 22, 2026]] to restore community footpaths. The funding notice [[v:PATH-5022]] includes [[q:“Start work only if the access plan is agreed.”]] All funded groups must discuss temporary access with nearby users before repairs begin. The commitment does not authorise closing a route without that discussion. Some repairs can proceed while a narrow passage stays open, but each site needs its own assessment. The foundation will retain the agreed access plan with the award record so that a later change in the work sequence does not quietly remove the promised route.
