This is an authored synthetic evaluation corpus, frozen on 2026-10-24. The 30 main sources contain ten status updates, ten incident notes, and ten press releases. All names and organisations are fictional. The injected source is kept outside the seeded split.

The `.src.md` files are the source of annotation truth. Short tags `[[n:...]]`, `[[d:...]]`, `[[e:...]]`, `[[q:...]]`, and `[[v:...]]` mark number, date, entity, quote, and verbatim facts. Tags cannot nest. `scripts/build-fixtures.ts` strips them while accumulating half-open UTF-16 spans. Gold spans describe the annotation; they are not copied from the application's extractor. For example, a unit that the extractor does not recognise still belongs in an annotated quantity.

`catalog.json` holds authored paths, provenance, trap labels, and frozen seed configuration. `manifest.json` adds stripped source text, gold spans, static word counts, the source split, and voice pairings. Runtime split and pairing logic has one implementation in `src/lib/evalkit/seededSplit.ts`: Mulberry32, descending Fisher-Yates, seeds 370037/370038. Ten source IDs are development sources; the other twenty are held out. Each source pairs with two distinct voices, producing twenty development and forty held-out pairs per system.

Files under `good/` are agent-authored substantive paraphrases, with number-format changes, reordering, and rewritten prose. They are annotation references, not independent human judgments or measured model successes. The additional injected paraphrase is excluded from the thirty-source corpus.

The terse and warm voices are original samples authored for this project. `gutenberg-placeholder.md` is also newly authored: **PLACEHOLDER — not Gutenberg**. It reserves the intended later literary slot; no Gutenberg text has been retrieved or verified. Results using that voice must carry the placeholder label. Static construction counts are 627, 679, and 635 words. Each sample is disjoint from every source under the eight-word copy-check rule.

`mock/scripts.json` is an explicit version-1 `ScriptsTable`. Every seeded pairing has B2 rewrite, B3 draft/check/revision, and three B4 attempt slots. The injected source has explicit rows for each voice. Scripted empty self-checks are authored behavior, not factual validation. B4 outputs contain namespace markers for protected spans; `ScriptedRewriter` substitutes the actual run namespace. Unknown keys throw `MockRecordingMissing`. No row is a fallback for an unlisted input.

`mock/recordings.json` is deliberately absent. The future `npm run recordings` generator uses actual prompt builders through `runPipeline`, actual fixture namespace derivation and masking, and actual retry checks/repair requests. Each reached model call is captured with canonical `recordingKey(model,messages,maxTokens)`, including prompt/mask versions. It also captures the bundled demo's distinct prompts. Corpus claims use overlap-only checks; no model judge replies or judge measurements are fabricated. Generated recordings remain scripted mock responses, even after generation.

During construction, only standalone file processing and the TypeScript syntax parser ran. Neither generator, application pipeline, test suite, evaluator, nor model provider has run. Deferred commands are `npm run fixtures`, `npm run recordings`, and the fixture tests after dependencies are installed. Switching the global mock mode to recordings also requires the demo factory to receive the generated file; its current factory accepts the bundled scripted table only.
